## ✨ What we do

| Discipline | Official description |
|---|---|
| 🧰 **Ports** | Windows-only software that now runs on Linux. |
| 🎮 **Mods** | Games made to do things their developers did not intend, mostly crash. |
| 🔥 **Fixes** | Three unrelated crash modes, one notebook, one working system. |

## 🔧 Method

1. Reproduce it.
2. Read the logs.
3. Distrust the obvious answer.
4. Find the actual cause.
5. Write it down so future-you doesn't have to do it again.
6. Forget you wrote it down so you have to debug it again.
7. Repeat.
